# Multilingua
Project description: This repository presents a prototype of a multilingual language resource of short functional texts, developed as part of a Master’s thesis in Computational Linguistics (Computational Linguistics and Internet Technologies in the Humanities) at Sofia University “St. Kliment Ohridski”. The corpus consists of short, pragmatically oriented texts (e.g. restaurant menus and medical leaflets) in Bulgarian, English, and French, structured in XML and enriched with morphosyntactic annotation following the principles of Universal Dependencies.
The project demonstrates an end-to-end workflow for structuring, validating, processing, and visualizing multilingual textual data, including XML validation with DTD, data extraction and transformation using Python, and web-based presentation via HTML. Access to the texts is provided through QR codes linking to a static web interface hosted on GitHub Pages, enabling multilingual access and parallel text visualization.
